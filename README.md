# CapStone_ML_Problem_Cornell_26
# 🧠 Census Income Prediction using Machine Learning

## Overview

This machine learning capstone explores whether demographic and employment-related features can predict whether an individual's annual income exceeds $50,000 using the U.S. Census Income dataset.

The project compares two supervised learning models—Logistic Regression and a Neural Network—while examining model performance, fairness, bias, and ethical considerations when using demographic information for prediction.

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- TensorFlow / Keras
- Matplotlib
- Seaborn

## Machine Learning Workflow

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Feature Engineering
- One-Hot Encoding
- Logistic Regression
- Hyperparameter Tuning (GridSearchCV)
- Neural Network Design
- Model Evaluation
- Ethical & Fairness Analysis

## Results

The project compares a traditional machine learning model (Logistic Regression) against a Neural Network using:

- Accuracy
- F1 Score

The results are discussed in terms of performance, interpretability, computational complexity, and fairness when making predictions from demographic data.

## What I Learned

Through this project I gained experience with the complete machine learning lifecycle, including data preprocessing, feature engineering, model training, hyperparameter tuning, neural network design, and evaluating ethical considerations when building predictive models.
